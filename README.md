# 🛒 E-Commerce Web Application

## 📖 Overview
The E-Commerce Web Application is a full-stack web project designed to provide users with a smooth online shopping experience. It allows users to browse products, manage their shopping cart, and place orders efficiently. The project demonstrates key web development concepts such as user authentication, database management, and CRUD operations.

---

## 🚀 Features

- User Registration and Login
- Secure Authentication
- Product Listing and Management
- Product Search Functionality
- Add to Cart
- Update and Remove Cart Items
- Order Placement
- User Profile Management
- Responsive Design
- CRUD Operations for Products

---

## ⚙️ Installation & Setup

### 1. Clone the Repository

```bash
git clone https://github.com/adarshkumar89/E-Commerce-Web-Application.git
```

### 2. Navigate to the Project Directory

```bash
cd E-Commerce-Web-Application
```

### 3. Install Dependencies

```bash
npm install
```

### 4. Start the Application

```bash
npm start
```

or

```bash
npm run dev
```
